# TP-Chess
TP pour la POO avancée en PHP avec les échecs dans le cadre du cours de développement back-end et conception de M1

## Commandes

Installer les dépendances :

```bash
composer install
```

Lancer les tests :

```bash
composer test
```

Executer index.php :

```bash
php index.php
```

Executer play.php (hors cadre) :

```bash
php play.php
```

Lint :

```bash
composer lint
```

Correction automatique du style :

```bash
composer lint:fix
```
